This page lists everything the CLI does. `rubix help` and `rubix help <command>` print the same list in your terminal, and `/help` or `?` shows the keys inside chat.

## Commands

| Command | What it does |
| --- | --- |
| `rubix` | Opens chat |
| `rubix chat [-s id] [-p text]` | Opens chat. `-s` opens an existing chat, `-p` sends a first message. |
| `rubix -p "question"` | Asks Rubix once, prints the answer and exits |
| `rubix ask "question"` | The same as `rubix -p` |
| `rubix browse [tab] [search]` | Opens [Browse](/cli/browse), such as `rubix browse tasks owner:me` |
| `rubix browse INC-12` | Opens one record in Browse |
| `rubix status` | Open critical and high incidents, what needs you, Tasks waiting and your environments |
| `rubix incidents [search]` | Lists incidents. Filters: `sev:high`, `env:prod`, `status:all` |
| `rubix rcas [search]` | Lists RCAs. Filters: `sev:high`, `env:prod` |
| `rubix tasks [search]` | Lists Tasks. Filters: `owner:me`, `priority:high`, `status:all` |
| `rubix artifacts [search]` | Lists the artifacts Rubix made |
| `rubix incident INC-12` | Shows an incident: what was detected, the RCA, Tasks and activity |
| `rubix rca RCA-4` | Shows an RCA |
| `rubix task TSK-30` | Shows a Task |
| `rubix artifact <id>` | Shows an artifact |
| `rubix sessions` | Lists your chats with their ids |
| `rubix model` | Lists the models your organization can use |
| `rubix login` / `rubix logout` | Signs in or out |

### Options

| Option | Works with | What it does |
| --- | --- | --- |
| `-e, --env <name>` | `-p`, `ask` | The environment to ask about |
| `--json` | `-p`, `ask`, `status`, lists, records | Prints JSON |
| `-n, --limit <n>` | lists | How many rows to show. 20 by default, up to 200. |

In a terminal, output has colour and links. When you pipe it, you get plain text. With `--json`, you get JSON.

### Asking once

`rubix -p` joins anything you pipe in to the question, so `cat error.log | rubix -p "what does this mean?"` sends the log with it. The chat is saved, and the CLI prints `rubix chat -s <id>` so you can carry on there.

If Rubix needs an approval or asks a question, the CLI says so, prints `rubix chat -s <id>` to answer it in chat, and exits with code 2. Other errors exit with code 1.

With `--json`, the answer looks like this:

```json
{
  "chat_id": "…",
  "answer": "…",
  "finished": true,
  "waiting": null
}
```

`waiting` says what Rubix is waiting for when it stopped for you.

## Slash commands

Type `/` in chat for the list. Your organization's saved commands from **Customize > Commands** show in the same list.

| Command | What it does |
| --- | --- |
| `/new` | Starts a new chat |
| `/resume` | Picks an earlier chat |
| `/delete` | Deletes this chat for good, in the console too |
| `/stop` | Stops Rubix's reply |
| `/mode` | Observe, Assist or Auto, up to your organization's highest mode |
| `/env [name]` | The environment Rubix looks at |
| `/model` | The model for this chat |
| `/effort` | How hard the model reasons |
| `/style` | quiet, normal or verbose |
| `/plan execute` / `/plan drop` | Runs or drops the plan Rubix wrote |
| `/browse` | Opens Browse |
| `/incidents`, `/rcas`, `/tasks`, `/artifacts`, `/chats` | Opens that tab in Browse, with an optional search |
| `/incident INC-12`, `/rca RCA-4`, `/task TSK-30` | Opens one record |
| `/refresh` | Refreshes environments and the home card |
| `/pet` | Shows or hides Rubix above the input |
| `/paste` | Pastes from the clipboard, for text too long for the terminal's paste |
| `/send` | Sends the last shell command and its output to Rubix |
| `/clear` | Clears the screen. The chat is kept. |
| `/status` | Shows who you're signed in as and the chat you're in |
| `/console`, `/docs` | Opens the console or these docs in your browser |
| `/untrust` | Removes this folder from the trusted list |
| `/login`, `/logout` | Signs in or out |
| `/help` | Shows the keys |
| `/exit`, `/quit` | Leaves the CLI |

## Keys in chat

| Key | What it does |
| --- | --- |
| Enter | Sends the message, or queues it while Rubix is answering |
| Shift+Enter | New line |
| Tab | Uses a starter question on the home card |
| Shift+Tab | Changes the mode |
| Left arrow | Opens Browse, when the input is empty |
| Up arrow | Edits the first queued message |
| `@` | Adds an incident, RCA, Task, environment or file |
| `!` | Runs a shell command, at the start of a line |
| `?` | Shows the keys, when the input is empty |
| Ctrl+G | Writes the message in your editor |
| Ctrl+O | Shows or hides Rubix's full work on the last reply |
| Ctrl+C | Stops Rubix's reply. Press it twice when idle to leave. |
| Ctrl+D | Leaves, when the input is empty |
| Ctrl+L | Clears the terminal |
| Ctrl+A / Ctrl+E | Start or end of the line |
| Ctrl+K | Deletes to the end of the line |
| Esc | Closes a list or panel, or skips Rubix's question |

When Rubix asks for approval: `y` approves once, `a` approves for this chat, `n` declines.
