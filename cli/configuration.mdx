The CLI works without any setup. This page is for when you want to know what it saves, or change how it shows things in your terminal.

## What the CLI saves

Everything lives in `~/.rubix/`.

| File | What's in it |
| --- | --- |
| `auth.json` | Your sign-in. `rubix logout` removes it. Treat it like a password. |
| `settings.json` | Your response style, the environment you last picked, and whether `/pet` is on |
| `sessions.json` | The titles and ids of your recent chats, so `/resume` opens quickly |
| `trusted-folders.json` | The folders you trusted |

You don't need to edit these files. Change the settings in chat with `/style`, `/env` and `/pet`.

The chats themselves are saved with your organization, not on your machine. That's why they show in the console too.

## What your organization decides

Some things come from your organization, not from the CLI:

- **The highest mode.** `/mode` and Shift+Tab can't go above it. An admin sets it in **Settings > Modes**. See [Modes](/using/modes).
- **The models.** `/model` lists the ones in **Settings > Models**. New chats start on the Primary model. See [Models](/using/models).
- **Saved commands.** Commands from **Customize > Commands** show in the `/` list. See [Customize](/using/customize).

## Environment variables

| Variable | What it does |
| --- | --- |
| `RUBIX_MOUSE=0` | Turns the mouse off in Browse |
| `RUBIX_MASCOT=0` | Shows plain text instead of the pixel Rubix |
| `RUBIX_LINKS=0` or `1` | Turns terminal hyperlinks off or on |
| `NO_COLOR` | No colour, and no pixel Rubix |
| `VISUAL`, `EDITOR` | The editor Ctrl+G opens. `vi` if neither is set. |

Set one for a single run, such as `RUBIX_MOUSE=0 rubix browse`, or export it in your shell profile.
