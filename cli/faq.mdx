---

<AccordionGroup>
  <Accordion title="Is the CLI a different Rubix from the console?">
    No. It's the same Rubix and the same chats. A chat you start in the terminal shows in the console, and the other way round.
  </Accordion>
  <Accordion title="Can the CLI change my infrastructure?">
    Rubix can change things only through the tools your organization connected, and only as far as the mode allows. In Observe, nothing that changes anything runs. In Assist, you approve each change with `y`. See [Modes](/using/modes).

    In Browse, actions such as closing an incident or moving a Task change the record in RubixKube, as you. Each one asks first.
  </Accordion>
  <Accordion title="Does Rubix run commands on my machine?">
    No. Commands you start with `!` run in your shell, and Rubix sees their output only when you send it with `/send`. Rubix reads a local file only when you name it with `@./path`.
  </Accordion>
  <Accordion title="Can I sign in with an API key?">
    No. The CLI signs in as you, with a code you approve in the browser. Everything it does is recorded under your name, as in the console.
  </Accordion>
  <Accordion title="Can I use it in CI?">
    The one-shot commands work in scripts, and `--json` and the exit codes are there for that. The CLI signs in as a person, though, so run it where that person would sign in, not on a shared runner.
  </Accordion>
  <Accordion title="Does it work on Windows, and over SSH?">
    It runs anywhere Node.js 22.12 or newer runs: macOS, Linux and Windows. Over SSH, copy the sign-in link into a browser on your own machine.
  </Accordion>
  <Accordion title="Does using the CLI count towards my plan?">
    The same as in the console. A chat isn't an investigation, so it doesn't count towards your monthly investigations, and its AI tokens show in **AI usage** like any other chat. **Run RCA again** writes a new RCA report, so it counts as one investigation. See [Usage and plan](/using/usage-and-plan).
  </Accordion>
  <Accordion title="Can I use the CLI with more than one organization?">
    The CLI uses your account's home organization. Use the console to work in another one.
  </Accordion>
  <Accordion title="Where do I see what changed in a release?">
    [What's new](/getting-started/whats-new) lists the main changes. The package's changelog on [npm](https://www.npmjs.com/package/@rubixkube/rubix) has every one.
  </Accordion>
  <Accordion title="Where do I report a bug?">
    Email [connect@rubixkube.ai](mailto:connect@rubixkube.ai) with `rubix --version`, `node --version`, your operating system and what you ran.
  </Accordion>
</AccordionGroup>
