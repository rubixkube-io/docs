The CLI is the npm package `@rubixkube/rubix`. It needs Node.js 22.12 or newer and a RubixKube account.

## Install

<Tabs>
  <Tab title="npm">
    ```bash
    npm install -g @rubixkube/rubix
    ```

    This gives you the `rubix` command.
  </Tab>
  <Tab title="npx">
    ```bash
    npx @rubixkube/rubix
    ```

    Runs the CLI without installing it. Each run fetches the package, so install it if you'll use it often.
  </Tab>
</Tabs>

Check it worked:

```bash
rubix --version
```

If your shell says `rubix: command not found`, the folder npm installs global commands into isn't on your `PATH`. Run `npm prefix -g`, and add the `bin` folder inside it to your `PATH`.

## Sign in

```bash
rubix login
```

<Steps>
  <Step title="Get a code">
    The CLI prints a link and a short code, and opens the link in your browser when it can.
  </Step>
  <Step title="Approve it in the browser">
    Sign in to RubixKube if you aren't already, check the code matches, and approve.
  </Step>
  <Step title="Back in the terminal">
    The CLI sees the approval and you're signed in. Running `rubix` for the first time does the same thing if you haven't signed in yet.
  </Step>
</Steps>

The sign-in is kept in `~/.rubix/auth.json` and renews itself, so you don't sign in every day. `rubix logout` removes it.

Over SSH, where no browser opens, copy the link into a browser on your own machine. The code works from any device.

## Trust the folder

The first time you open chat in a folder, the CLI asks whether you trust it, because Rubix can read the files you name there with `@./path`. Choose **Trust this folder and continue**, or press Ctrl+C to leave. `/untrust` removes the current folder from the list. One-shot commands don't ask.

## Update

```bash
npm install -g @rubixkube/rubix@latest
```

The CLI checks npm once a day and tells you when a newer version is out. [What's new](/getting-started/whats-new) lists what changed.

## Uninstall

```bash
npm uninstall -g @rubixkube/rubix
rm -rf ~/.rubix
```

The second line removes your sign-in and settings. Leave it out if you'll install the CLI again.
