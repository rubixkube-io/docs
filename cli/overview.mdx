The Rubix CLI is for when you're already in a terminal and don't want to switch to a browser to ask Rubix something or check an incident. It's the same Rubix and the same organization as the console, so a chat you start in one shows up in the other.

```bash
npm install -g @rubixkube/rubix
rubix
```

## When you'd use this

- **You're reading logs and something looks wrong.** Pipe them in: `cat error.log | rubix -p "what does this mean?"`.
- **You want to see what's open without leaving the shell.** `rubix status` lists the critical and high incidents, what needs you, the Tasks waiting and your environments.
- **You're working an incident.** Open it in Browse, read what Rubix found, run the RCA again, comment, or ask Rubix about it with one key.
- **You want Rubix in a script.** One-shot commands print plain text or JSON and exit, so they fit in an alias, a cron job or a runbook.
- **You'd rather write in your editor.** Ctrl+G opens the message in `$VISUAL` or `$EDITOR`, and saving brings it back.

## Three ways to use it

| | Start it with | What it's for |
| --- | --- | --- |
| **Chat** | `rubix` | A conversation with Rubix. Approvals, questions and modes work as in the console. |
| **Browse** | `rubix browse`, or the left arrow on an empty input | Full-screen lists of incidents, RCAs, Tasks, artifacts and chats, with actions on single keys. |
| **One-shot commands** | `rubix -p "..."`, `rubix status`, `rubix incidents` | Print an answer or a list and exit. For scripts and quick checks. |

## Same Rubix as the console

The CLI talks to the same Rubix as the console's chat.

- **Chats are shared.** A chat started in the terminal is in the console's chat list, and the other way round. A reply keeps running if you close the terminal, and reopening the chat follows it.
- **Same controls.** Pick the model and effort, the response style (quiet, normal or verbose) and the mode (Observe, Assist or Auto). The mode can't go above your organization's highest mode. See [Modes](/using/modes).
- **Same records.** Incidents, RCAs and Tasks use the same codes, such as INC-12, RCA-4 and TSK-30.

## Requirements

- Node.js 22.12 or newer.
- A RubixKube account. Sign up at [console.rubixkube.ai](https://console.rubixkube.ai).
