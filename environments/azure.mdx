---

If you run on **Azure Kubernetes Service**, you can connect now. An AKS cluster installs like any other cluster, with the same command. See [Kubernetes](/environments/kubernetes).

Azure as a whole, meaning a subscription with its VMs and other services, isn't in the **Connect** picker in the console yet. To connect a subscription, email [connect@rubixkube.ai](mailto:connect@rubixkube.ai) and we'll work through it with you.

A single Azure VM can also connect as a [server or VM](/environments/vm). You'll see that machine, not the subscription.
