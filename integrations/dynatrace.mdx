---
title: "Dynatrace"
description: "Let Rubix read Dynatrace by adding its MCP server as a custom integration."
---

Connect Dynatrace so Rubix can query problems, logs, metrics and traces while it investigates. It connects as a custom MCP server, which is **Business and Enterprise**.

## Connect it

<Steps titleSize="h3">
  <Step title="Create a token in Dynatrace">
    Create a platform token in Dynatrace with read access to the data you want Rubix to see.
  </Step>
  <Step title="Add the server">
    Go to **Customize > Integrations** and choose **Add your own**. Pick **MCP server** and enter this address, with your environment id:

```text
https://<environment>.apps.dynatrace.com/platform-reserved/mcp-gateway/v0.1/servers/dynatrace-mcp/mcp
```
  </Step>
  <Step title="Paste the token">
    Set **Sign-in** to **Token**, paste the platform token and choose **Add**.
  </Step>
  <Step title="Check it">
    Choose **Check connection**. Rubix finds the server's tools when it connects.
  </Step>
</Steps>

## What Rubix can read

The tools come from Dynatrace's own server, and the **Tools** list shows each one. Rubix sees what the token can see.

To send Dynatrace problems to RubixKube as incidents, point a Dynatrace webhook at [your own webhook](/integrations/webhooks).
