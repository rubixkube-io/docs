---
title: "GitHub"
description: "Let Rubix read your repositories, commits and pull requests while it looks for what changed."
---

Connect GitHub so Rubix can see what changed before something broke. If `orders-api` starts failing after a release, Rubix can read the commits and pull requests in that release and cite them in the RCA.

## Connect it

GitHub connects with a token. There's no sign-in option.

<Steps titleSize="h3">
  <Step title="Create a token in GitHub">
    Create a personal access token in GitHub. Give it read access to the repositories you want Rubix to see, and no more.
  </Step>
  <Step title="Paste it in RubixKube">
    Go to **Customize > Integrations**, pick **GitHub** and paste the token as a **Personal access token**.
  </Step>
</Steps>

## What Rubix can read

RubixKube connects in read-only mode, so Rubix can read repositories, commits, pull requests and issues but can't write to GitHub through this connection.

The token decides what Rubix can see. If a repository is missing, give the token access to it, then use **Replace token**. Press **Test** to run [the Reads check](/integrations/overview#see-what-a-connection-can-read).
